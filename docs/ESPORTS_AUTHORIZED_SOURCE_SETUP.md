# Esports source setup (restricted data)

CS2: the pinned Aokua player CSV is entirely 2015–2020, and cannot be counted as CS2. OpenCS2 (blanchon/opencs2_dataset_demo, CC BY 4.0) provides actual April 2026 map metadata. The workflow downloads only Parquet metadata, never demos, and does not publish player rows. Owner reports CS2 source access. Underlying rights and cross-source player identity still require review.

For original esports offers: use an authorized export from PrizePicks or Underdog, not a scraped mirror or demo. The workflow only calls an explicitly configured official HTTPS export with an approved read-only bearer token and a no-metered-charge confirmation. No export URL is guessed. Configure secrets PP_ESPORTS_EXPORT_URL and PP_ESPORTS_EXPORT_TOKEN or UD_ESPORTS_EXPORT_URL and UD_ESPORTS_EXPORT_TOKEN; set variable ESPORTS_NO_METERED_EXPORT_APPROVED=1 only if the source is truly no-charge and permitted. Never paste credentials into issues or commits. Independent provider keys are checked for presence only, not charged. If the user's provider has a different native schema, implement its documented adapter before enabling. Transport authentication is NOT proof of app availability, payouts, or grading.

Expected normalized export envelope: kind=authorized_esports_original_offer_export_v1, platform=PrizePicks or Underdog, isDemo=false, exportId, sourceUrl, capturedAt, rows (existing validOffer contract plus explicitly source-proven originalPlatformOfferVerified and authorizedExportVerified). Original source response hash and capture timestamp are retained in restricted Git. Rows are not authenticated just because a supplied boolean is true; independently review source receipts before model/lineup eligibility. No raw public records, no wagers, no model promotion.
