# Three-provider integration, 2026-11-24
- OpenDota public GET /proMatches and /matches/{id}, https://opendota.apidocumentation.com/. One bounded index call and at most five new detail calls daily (1.1 s spacing, stop 401/403/429, no paid endpoints or credentials). Deduplicate previously captured game IDs. Index and detail must agree on start/end, team IDs, scores, winning team and native series ID. Full 10-player professional boxscore, explicit slots and stats. Provider-reported final is not independent verification. Series ID does not determine game ordinal. No prop grading until exact map scope and cross-source identity reviewed.
- PandaScore https://developers.pandascore.co/docs/plan-reference. Free fixtures list endpoints for csgo (CS2), valorant, lol, dota2, codmw. Up to 20 upcoming and 20 past per sport, ten GETs max. No paid game/player statistics calls. Source terms https://www.pandascore.co/terms-and-condition restrict odds-related use; obtain permission for this project before collection. Credentials: PANDASCORE_API_KEY (or PANDASCORE_TOKEN/PANDASCORE). Explicit authorization and zero-charge confirmation required; do not set PANDASCORE_BETTING_DATA_AUTHORIZED or PANDASCORE_NO_CHARGE_CONFIRMED without provider confirmation.
- Riot GRID https://grid.gg/riot-open-access/ explicitly excludes gambling. Implement Central Data and minimal Series State queries per official documentation https://grid.helpjuice.com/how-do-i-use-the-central-data-api and https://grid.helpjuice.com/3619413. Credential GRID_API_KEY (or RIOT_GRID_API_KEY/GRID) plus verified permission for this specific use and no-charge entitlement. Do not set GRID_BETTING_DATA_AUTHORIZED or GRID_NO_CHARGE_CONFIRMED without provider confirmation. No query on missing permission/key. Up to three GraphQL queries total. Only LoL/Valorant source-native fixtures and completed-series candidate player kill/death records; no inferred map ordinals. Grid endpoints and fields still require live entitlement validation.
- Private archive branch research/esports-free-providers, immutable new files only, no raw public rows. All data remains unreviewed source-native evidence, not authenticated prop lines or official platform results. Daily UTC 16:20 (08:20 Pacific standard time), manual dispatch and main update. No other repositories changed except private archive where verified.
