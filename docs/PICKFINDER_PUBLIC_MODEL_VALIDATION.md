# Public PickFinder research validation

Public-only validation runs separately from the live collector. Validate manifests and individual chunk digests; separate source observations, exact cross-book comparisons, explicit two-sided sportsbook prices and model qualification. NBA official season histories and schedule are obtained without paid requests. Historical team + exact name creates only candidate event mappings; a separately reviewed preforecast crosswalk is mandatory for actual model joins. No private archives, original app certification or production approval. Official NBA finals grade newly frozen public forecasts only, not old private pilot frames. Other sports need source-native identity, historical statistics and final-result adapters. Existing model unchanged. Retrospective evaluation is not untouched testing. Lineup uncertainty remains conditional; no all-hit estimate from conditional marginals.

Reviewed crosswalks: immutable JSON under research/pickfinder-public-validation-v1/reviewed-crosswalks/<sha256>.json, kind pickfinder_public_independent_crosswalk_v1, with source scope (sport,detailId,eventId,market,period,mapRange,gameMode), sourcePlayer, nativePlayerId, nativeEventId, nativeMarket, team, verifiedStartAt, independentReviewVerified, verifiedAt, identityEvidenceSha256. No automatic promotion of name candidates.
