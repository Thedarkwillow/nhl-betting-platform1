# Public NFL native history

Source: nflverse contributors, https://github.com/nflverse/nflverse-data, via nflreadpy. The general data license is CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Exclude FTN, participation and other separately licensed data. See https://nflreadpy.nflverse.com/ and https://nflreadr.nflverse.com/reference/load_rosters_weekly.html. Normalized regular-season 2024–2026 schedule, explicit weekly ESPN and GSIS identities, game-scoped player stats. Duplicate identities quarantined, missing statistics not treated as zero. No raw provider response, no PickFinder automatic identity promotion. Native crosswalk requires the same explicit ESPN ID, weekly GSIS mapping, kickoff and team pair, not name. Final scores are retrospective evidence, not original app settlement. NBA schedule fallback reuses official public preview + ESPN pregame corroboration, only when CDN schedule unavailable. Official NBA historical data still pending if stats endpoint refuses. No private access.
