# Live PickFinder progress

Open the public Actions run and expand Authorized private research capture. `deep_research_progress` prints the deduplicated queue, current-version completion, legacy counts, remaining scopes, percentage, sport/platform totals and latest archived board pagination. `deep_scope_checkpoint_verified` prints after each remotely verified scope; every ten attempts prints the expanded breakdown. `deep_dashboard_page_verified` prints known per-scope pagination, unknown when not exposed. `prop_board_live_progress` prints observed rows and collected versus remotely verified pages every ten pages, and at first/last. The completed step writes a job summary table. The running workflow revision cannot be changed mid-run. A queue is a snapshot, not a promise that all future props or filter combinations are known. Raw source data and credentials remain private.
