# PickFinder capability boundaries

Public first-party documents reviewed November 26, 2026 Pacific. Publisher claims and existing project verification are separate. A feature missing from an observed view is unverified there, not necessarily unsupported everywhere.

| Capability | What the publisher documents | What the project can rely on |
| --- | --- | --- |
| Premium web and iOS research | Player prop trends, filters, projections, matchups, sportsbook comparisons and movement, Discrepancies and Pick Builder. | Archived features are scoped by exact captured book, sport, market, time and view. Same-browser builder persistence is verified. Multi-device sync, native export, individual operator available sides, entry terms and settlement are not. |
| Premium Discord | A membership-linked community with daily picks and support. | This is different from the owner-controlled project alert channel. Neither community access nor an iOS listing verifies native alert delivery to Discord. No private community data is collected. |
| iOS and Android | The publisher's listed app is distributed by Apple's App Store. The project's prior web UI evidence describes board-drop delivery via iPhone. | Actual native iPhone delivery and browser push are unverified. Android native app/push is not established by these sources. Use the project-owned Discord receipt, where present, as separate evidence. |
| Native board alerts, player alerts and custom notification filters | Publisher advertises line-movement alerts, but not a delivery guarantee. | Existing web evidence has per-book/sport board-drop settings. Individual Players, +EV Picks and Custom Filters notification options previously displayed **Coming soon**. This is separate from dashboard or research-table filters. Do not mark these native categories integrated. |
| Pro tools | Dedicated EV+, Arbitrage and Middles boards are Pro. The pricing page also mentions some +EV calculations under Premium, which does not prove the dedicated Pro board is included. | Pro-only boards excluded. No upgrade, native alert activation, entry submission or paid usage. |
