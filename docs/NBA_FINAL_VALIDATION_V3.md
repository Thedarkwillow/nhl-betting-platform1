# NBA final validation v3 (research only)

Run `node scripts/run-nba-final-validation-v3.cjs /private/input.json > /private/report.json` offline. No API calls or model promotion. The caller must export the real source evidence; this runner does not collect data or authenticate claimed source content.

Input object:
- `injuries`: rowId, date (YYYY-MM-DD), gameId, team, player, status, publishedAt, sourceUrl (official NBA).
- `roster`: playerId (NBA namespace), name, team, from, through, effectiveAt, sourceUrl (official NBA); optional reviewedAliases. Use dated roster/transaction evidence, not today's roster or future played-game appearances. Review aliases manually. Unresolved and ambiguous IDs remain null.
- `datasets`: development, calibration, holdout, independent arrays. Each row: date, gameId, playerId, team, opponent, market, line, actual, y (1 if actual exceeds line), baselineP, lineSourceUrl, featureCutoffAt, tipAt. Real half-point lines only; verify line capture timing and settlement upstream. NBA game/player IDs must be in the same namespace across inputs. Optional marketP (verified no-vig benchmark).
- Optional context: teammateId (one teammate selected by a predeclared prior-only role rule); opponentPace {opponent, ratio, sampleGames, asOf, sourceUrl}; positionalDefense {opponent, position, market, ratio, sampleGames, asOf, sourceUrl}, plus position, positionSourceUrl and positionAsOf. Ratios represent opponent pace relative to league and opponent position/market production relative to league, respectively. They must be calculated using only data prior to featureCutoffAt. Missing injury rows do not imply availability. Never treat a current-game DNP as historical pregame evidence.

All four datasets must be chronologically ordered with disjoint game IDs. The earlier Feb–Mar 2025 reserved cohort cannot test a model fitted on 2026 data without leakage; it needs earlier development/calibration data, or an independent later cohort. Empty partitions produce no qualifying evidence. Model fitting uses development only, calibration uses calibration only; holdout and independent results are reported without model selection. Feature comparisons use matched rows. Calibration minimum: 100 rows, 30 games, 10 dates per market and two outcome classes. These thresholds are screening rules, not proof of generalization. The absence effect is observational, not causal. Confidence intervals, externally authenticated archive provenance, prior-use checks, and independent prospective results remain necessary before model freeze.

The runner reports a SHA-256 of the input file, but this does not prove the file was untouched before the run. Keep inputs and outputs in private authorized storage. No paid provider requests, production model changes or public data redistribution.
